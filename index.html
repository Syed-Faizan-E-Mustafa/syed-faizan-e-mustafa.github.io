Max Hustle Uploader

Max Hustle Uploader is the publishing tool for the Max Hustle YouTube channel (@MeetMaxHustle). It uses the YouTube Data API, with the channel owner's authorisation, to upload the channel's own videos and Shorts, set their titles, descriptions, thumbnails, captions and publish schedules, and read the channel's own statistics. It does not access any other user's data, is only used by the channel owner, and is not a public service.
